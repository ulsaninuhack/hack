## 기록 규칙

- 상태는 `구현 중`, `리뷰 대기`, `수정 중`, `검토 완료` 중 하나를 사용한다.
- UI 변경 PR의 Preview URL을 정확히 기록한다.
- Claude가 찍은 두 viewport 스크린샷의 링크나 아티팩트 경로를 남긴다.
- punch-list 항목별 수정 PR 또는 커밋을 연결한다.
- 자동 게이트 통과만으로 `검토 완료`를 쓰지 않는다.
