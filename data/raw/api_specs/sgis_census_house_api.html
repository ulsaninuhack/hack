총조사 주요지표 조회 API

요청주소

https://sgisapi.mods.go.kr/OpenAPI3/stats/population.json

요청정보(Body)

요청변수 값 Optional 설명
accessToken String 필수 액세스토큰
year *인구/주택 관련 데이터 인 경우
  2015년(2015) ~ 2024년(2024)

*사업체 관련 데이터 인 경우
  2000년(2000) ~ 2024년(2024)

*농가/임가/어가 관련 데이터 인 경우
  2000년 : 2000
  2005년 : 2005
  2010년 : 2010
  2015년 : 2015
  2020년 : 2020 		필수 기준연도
adm_cd non : 전국 시도 리스트
2자리 : 해당 시도
5자리 : 해당 시군구
8자리 : 해당 읍면동
선택 행정구역코드
low_search 행정구역코드에 해당하는 정보만 요청 : 0
1단계 하위 행정구역 정보 요청 : 1
2단계 하위 행정구역 정보 요청 : 2
(default : 1) 		선택 하위 통계 정보 유무

응답정보

출력변수 값 설명
adm_cd String 행정구역코드
adm_nm String 행정구역명
* 집계구에서는 나오지 않음
tot_ppltn String 총인구
avg_age 소수점 한자리 평균나이(세)
ppltn_dnsty 소수점 두자리 인구밀도(명/㎢)
aged_child_idx String 노령화지수(일백명당 명)
oldage_suprt_per String 노년부양비(일백명당 명)
juv_suprt_per String 유년부양비(일백명당 명)
tot_family String 총가구
avg_fmember_cnt 소수점 한자리 평균가구원수
tot_house String 총주택
nongga_cnt String 농가(가구)
nongga_ppltn String 농가 인구
imga_cnt String 임가(가구)
imga_ppltn String 임가 인구
naesuoga_cnt String 내수면 어가(가구)
naesuoga_ppltn String 내수면 어가 인구
haesuoga_cnt String 해수면 어가(가구)
haesuoga_ppltn String 해수면 어가인구
employee_cnt String 종업원수(전체 사업체)
corp_cnt String 사업체수(전체 사업체)

요청정보(Body)

선택 행정구역코드

household_type 세대구성코드표 참고 선택 세대구성별
다중선택 시 1,2,3 형태로 작성
ocptn_type 점유형태코드 참고 선택 점유형태
다중선택 시 1,2,3 형태로 작성
* 2010년까지 제공, 2015년도 이후는 제공하지 않음

출력변수 값 설명

* 집계구에서는 나오지 않음
household_cnt String 가구수
family_member_cnt String 총 가구원 수
avg_family_member_cnt String 평균가구원수
